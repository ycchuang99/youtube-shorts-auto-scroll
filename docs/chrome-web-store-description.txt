YouTube Shorts Auto Scroll

Enjoy YouTube Shorts more easily ✨

This extension automatically scrolls to the next Shorts video when the current one ends, so you can keep watching without clicking every time.

It also helps you skip ads and adjust playback speed for a smoother viewing experience.

Why you'll like it:
• Auto scroll to the next Shorts video
• Skip ads automatically
• Change playback speed anytime
• Simple popup controls
• Lightweight and easy to use
• Privacy-friendly 🔒 No data collection

Just install it, open YouTube Shorts, and enjoy hands-free viewing 🎬
